# AI / Coding Agent Entry Point

Before planning or modifying this repository, read every Markdown file under `/docs`, beginning with `/docs/README.md`.

- Docker is the project development runtime.
- Inspect existing code before proposing architecture changes.
- Plan focused changes before implementation.
- Keep controllers thin and recommendation rules outside the controller.

- Do not implement unrelated future roadmap features.
